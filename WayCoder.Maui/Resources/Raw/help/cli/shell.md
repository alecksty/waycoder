# 命令行页

手机上是一个**真 shell**（Android 走 `/system/bin/sh`），你在电脑上会敲的命令这里基本都能敲。

## 基本用法

- 输入框敲命令 → 点 **运行**（或回车）
- 左上 **清屏** 清掉历史输出
- `cd` 会**改变下面的工作目录**（提示符 `~/examples>` 会跟着变）
- 路径支持 `~/` 缩写（工作区根 = `~`）

## 能跑什么

- 普通命令：`ls`、`cat`、`cp`、`mv`、`grep`、`find`…
- **`vml` 命令**：编译运行 VML 程序（见「vml 命令」那篇）
- 你自己的脚本

## 运行长时间命令

程序跑很久时：

- 输入框那一格会显示 `⋯`（表示还在忙）
- 想中断就点 **■**（会连同子进程一起终止）
- 提示符 `~>` 重新出现 = 这一轮结束了（不是卡死）

## 和「对话」的区别

- **对话**：让 AI 替你干活，它自己去调工具、读文件、改代码
- **命令行**：你自己动手，AI 不参与

两边看到的**是同一个工作区**，文件互通。
