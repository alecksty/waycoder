# 隐私政策

这一页说明道码会接触哪些数据、把它们发到哪里、在手机上存了什么、以及怎么删掉。

**一句话**：道码**不运营任何服务器**，不收集数据、不上报统计、不含广告。
你的代码与对话只会发往**你自己配置的**模型服务商。

_最后更新：2026-09-29_

## 1. 发往模型服务商的数据

道码是一个 AI 编程助手，它的工作方式就是把上下文交给大模型。以下内容会通过 HTTPS
发往**你在设置里填的**那家服务商（地址与 API Key 都由你填，可以是 DeepSeek、OpenAI、
Claude、Gemini、OpenRouter，也可以是你自己搭的、或手机上的本地模型）：

| 内容 | 说明 |
|---|---|
| 你的提问 | 你在对话页打的字 |
| 对话历史 | 本次会话里累积的上下文（含压缩后的摘要） |
| 读到的文件内容 | 它用工具读过的**文件正文** |
| 命令输出 | 运行命令后的输出 |
| 图片 / 音频 | 仅当你用「看图」「语音转文字」时才发送对应文件 |
| 系统提示词 | 程序自己生成的说明（含项目结构等） |

⚠ **它会自己决定读哪些文件**。工作区里如果有密钥、证书、`.env` 这类敏感文件，
它可能读到并发给服务商。请把敏感文件排除在项目之外，或先切换到**计划模式**（只读）。

**发送给谁完全由你的配置决定** —— 我们不做任何转发、代理或二次上传，
也**接触不到**这些内容（Key 是你的，服务商账号也是你的）。

## 2. 其他对外请求

除模型服务商外，下面这些功能会联网，且**只在你（或 AI）真正用到时才发生**：

| 功能 | 目标 | 发送内容 |
|---|---|---|
| 联网搜索 | 搜索引擎 | 搜索关键词 |
| 抓取网页 / 下载 | 你或 AI 指定的网址 | HTTP 请求 |
| 语音转文字 | 你配置的 Whisper 兼容服务 | 待转写的音频 |
| MCP 服务器 | 你自己配置的服务器 | 由该协议决定 |

## 3. 手机上存了什么

都存在**本机**，不会上传到我们这边（我们也没有可上传的服务器）：

| 存什么 | 存在哪 |
|---|---|
| API Key | 应用私有目录的 `api_keys.json`（**明文，未加密**） |
| 设置、连接、模型选择 | 应用私有目录的配置文件 |
| 会话记录、记忆 | 应用私有目录的 `sessions/`、`memory/` |
| 你的代码与项目 | 工作区目录（见下） |

**工作区在哪**：默认在应用私有目录里。Android 上如果你授予了「所有文件访问」，
工作区与配置会改用外部存储的 `waycoder/` 目录 —— 这样别的文件管理器也能看到你写的代码。
iOS 上始终在应用私有目录内。

⚠ **Key 是明文的**：能读到本机这块存储的人就能读到它。请不要在多人共用的设备上
存放生产环境的密钥。

## 4. 申请的手机权限

| 权限 | 什么时候申请 | 用来做什么 |
|---|---|---|
| 相机 | 你点「拍照」时 | 拍一张照片给 AI 看 |
| 照片 | 你点「选图」时 | 选一张已有的图给 AI 看 |
| 麦克风 | 你点「语音输入」时 | 把说的话转成文字 |
| 所有文件访问（仅 Android） | 你主动去系统设置里开 | 让工作区放到外部存储，方便你用别的 App 打开代码 |

一律**用到才申请**，拒绝也能用其余功能（只是那一项不可用）。

## 5. 没有遥测

道码不包含统计上报、崩溃上报或广告 SDK。唯一的联网检查是**你主动触发**的版本更新查询，
它只读取版本号，不发送任何本机信息。

## 6. 怎么减少外发、怎么删

- 敏感目录就用**计划模式**（只读，不改文件）；纯聊天用**聊天模式**（不调用任何工具）
- 不想让数据出本机，就把服务商指向**本地模型**（如手机或电脑上的 Ollama）
- **删数据**：卸载 App 会清掉应用私有目录里的一切（Key、会话、设置）；
  如果你开过「所有文件访问」，工作区在外部存储，需要你手动删除 `waycoder/` 目录

## 7. 儿童与年龄

道码面向具备编程基础的开发者，**不面向 13 岁以下的儿童**，也不会刻意收集他们的信息。
商店年龄分级为 **13+**。

若你未满 18 岁，请在监护人同意后使用；填写模型服务商 API Key 之前，先确认已获得允许
—— 那把 Key 产生的费用由账号持有人承担。
