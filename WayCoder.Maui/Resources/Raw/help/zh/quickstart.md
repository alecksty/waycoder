# 五步跑起第一个程序

## 1. 填一把钥匙

底部 **设置** → 选服务商（DeepSeek / OpenAI / Claude / Gemini…）→ 填 API Key。
没有 Key 也能用「命令行」页跑程序，但对话功能用不了。

> Key 只存在手机本地（`api_keys.json`），不会上传到别处。

## 2. 选个模型

**设置 → 模型**：每行显示「供应商 + 模型名」。
想省钱就把「小模型」也选上 —— 压缩上下文、生成摘要这类杂活会交给它。

## 3. 说一句话，让它干活

**对话** 页直接打字，例如：

- 「在工作区写一个 hello.c，打印九九乘法表」
- 「把 examples/c/tetris.c 里的方块下落速度调慢一点」
- 「看看 examples/python/tetris.py 是怎么处理按键的」

每轮结束会在气泡下方显示**用时 / token / 费用**。

## 4. 跑起来看看

**文件** 页 → 点开一个文件 → 选 **VML 运行**。
手机上 C 语言的前端编译要**一两分钟**，别当卡死。

也可以直接在 **命令行** 页敲：

```
vml run examples/c/tetris.c
```

## 5. 改代码

**文件** 页点开文件 → 右上角 **✎** 解除只读 → 直接改 → **保存**。
写完点工具栏的 ▶ 就地编译运行，报错会**画在出错那一格上**。
