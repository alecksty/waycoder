# 文件管理

**文件** 页是你的工作区（沙箱），AI 改的文件也都在这里。

## 导入

顶部工具栏可以：

- **导入项目**：把电脑上的一个项目目录放进来
- **新建文件 / 新建目录**

也可以让 AI 直接写：

> 「在工作区建一个 mygame/ 目录，里面放一个 main.c」

## 打开

**点文件名** → 弹出菜单：

| 菜单项 | 干什么 |
|---|---|
| 打开 | 进编辑器（默认**只读**，防误改） |
| VML 编译 | 编译成下一级产物（见下） |
| VML 运行 | 编译并运行 |
| 用外部应用打开 | 交给系统（看图、看 PDF、听音频…） |
| 重命名 / 删除 | 就是字面意思 |

## 文件名有颜色，是有讲究的

| 颜色 | 含义 |
|---|---|
| **绿** | VML 能编译的源码（22 种语言） |
| **橙** | `.vml`（文本汇编） |
| **红** | `.vmb`（二进制字节码） |
| 不变色 | 其他文件（README、图片…） |

颜色只用来标「**这个能编 / 能跑**」，不是「源码就该是绿的」——
满屏彩色反而看不出重点。

## 「VML 编译」编出什么

按当前文件决定，不用你选：

```
main.c   ──▶  main.vml       （源码 → 文本汇编）
main.vml ──▶  main.vmb       （文本汇编 → 二进制字节码）
main.vmb ──▶  （已是终态，只能运行）
```

如果**同名产物已存在**，会问你「覆盖 / 重命名 / 取消」——
产物是可能被你手改过的文件，静默覆盖不可逆。
