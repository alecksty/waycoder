# 编辑与查找替换

## 改一行

**点那一行**就进入编辑态（那一行上会浮出一个输入框，光标跟着你的手指落点）。

- 回车 = **在这一行断成两行**（不是"另起一行"）
- 断行时新行会**继承缩进**；上一行以 `{` `(` `[` 结尾的话，还会**多缩进一级**
- 敲 `(` `[` `{` 会自动补上另一半，光标停在中间
- 再敲一次已经在那儿的右括号，会**跨过去**（不会变成 `())`）

## 撤销 / 重做

工具栏 **↶ ↷**，或 ☰ 菜单里同名项。
连续打字会自动合并成一步（不会一个字一个字地退）。

## 选区

**长按**选词，按住拖动可以扩选、跨行选。
选中后下方出现操作条：复制 / 删除 / 全选 / 粘贴 / ✕。

## 查找

☰ 菜单 →「🔍 查找…」，输入要找的文字，跳到**当前文件里**第一个匹配（从光标处往后找，找不到就绕回开头）。

## 替换

☰ 菜单 →「🔁 替换…」：填查找内容 → 填替换为 → 选：

- **替换全部**：一次改完，而且**整个操作是一步撤销**
- **只替换下一个**：从光标处开始，改第一处

> 只对**可编辑**的文件有效。大文件是只读打开的，会明确告诉你不能替换。

## 辅助输入条

代码里常见的符号（`(` `)` `[` `]` `{` `}` `<` `>` `"` `'` `;` `:` …）都在屏幕下方一条可以点的小板子上，
不用来回切输入法。

- **⌨** 键开关它；整条可以**拖着挪位置**
- 三张分类表：**符号 / 运算符 / 关键字**
- 关键字表会**按当前文件的语言自动换**（`.c` 给 C 的关键字，`.py` 给 Python 的）
- ⭐ 高频的排在前面
- **⌫** 是应用自己的退格 —— 有些输入法的退格到不了应用，这个一定能用
- 10 秒不动会缩小变淡，点一下就回来

## 换行 / 编码

设置 → 编辑器里可以指定保存时用什么编码（UTF-8 / 带 BOM / UTF-16 / 本地 OEM）和换行符。
**默认"保持原样"** —— 打开看一眼再保存，不会把你的 GBK 文件悄悄转成 UTF-8。
