# 编译运行与诊断

## 就地跑

工具栏那一格会**按文件类型变形**：

| 文件 | 那一格是 | 点了会 |
|---|---|---|
| 能编译的源码（`.c` `.py` …） | **▶ 运行** | 编译 + 链接 + 跑，输出在底部面板 |
| Markdown（`.md`） | **👁 预览** | 渲染表格与标题 |

跑起来的程序如果需要**键盘输入**，底部面板会出现一个发送框，打一行回车送进去。

## 停下来

底部面板右侧 **■** 停止。停不掉的程序可以按返回键退出窗口。

## 报错画在代码上

编译失败时，错误**直接标在出错那一行**：

- 行尾出现一行**气泡**，写着错误信息（多个错误会自动错开避免重叠）
- 出错位置画**波浪线**（红=错误 / 橙=警告 / 绿=提示）
- 底部面板切到「错误」页，列出全部问题，点一条跳到那一行

气泡是**代码的一部分**：你滚动它跟着滚、缩放它跟着缩，位置只由代码坐标决定。

> ⚠ 你**一动手改代码**，上一轮的错误就会被清掉 —— 那些行号多半已经偏了，
> 继续浮在代码上等于给你看假信息。

## 状态栏

底部一行显示：`编码 · 只读/编辑 · 行数 · 大小 · 光标位置 · 字号`。
一眼能看出"我现在能不能改、光标在哪"。
