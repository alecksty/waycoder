# 服务商与模型

## 填 API Key

**设置** → 选服务商 → 填 Key。

内置了一批主流服务商（DeepSeek / OpenAI / Claude / Gemini / 通义 / Kimi …），
也可以自定义地址（任何 OpenAI 兼容的网关都行）。

## 选模型

**设置 → 模型** 进模型管理：

- 按**供应商分组**，每行显示上下文长度与价格（免费的标绿）
- 右上角可以切「设为大模型 / 设为小模型」
- 已经选中的会显示 `大✓` / `小✓`

也可以在对话页的 **☰ 菜单 → 模型选择** 里快捷换。

## 大模型与小模型

- **大模型**：干正事（写代码、分析、决策）
- **小模型**：干杂活（压缩上下文、生成摘要）

**两个都选上最省钱**：杂活交给便宜的小模型，正事才用贵的。
没选小模型的话，杂活会让大模型自己干。

## 模型回退链（桌面版）

可以配一串模型，主模型失败时自动往下试。手机版暂未提供。

## 别的服务商也能用

只要兼容 OpenAI 的 `/v1/chat/completions`，填上地址和 Key 就能用。
「模型管理 → 导入」还能从 Claude Code / Codex / OpenCode 等工具的配置里**批量导入**。
