#### 概述

R 语言是一种用于统计计算和图形展示的编程语言和环境。本编译器实现了 R 语言的核心语法子集，支持向量化数据操作、统计函数、控制流和自定义函数定义。编译产物为 VML 汇编，可进一步翻译到 16 种目标架构。

编译器架构遵循标准 VML 前端模式：

```
R 源码 (.r) → Lexer (Lexer.cs) → Token 流
             → Parser (Parser.cs) → AST (ASTNode.cs)
             → CodeGenerator (CodeGenerator*.cs) → VML 程序
```

入口文件 `RCompiler.cs` 编排整个编译流水线，包括预处理、词法分析、语法分析、代码生成和标准库链接。

#### 支持的特性

##### 数据类型

| 类型 | R 表示 | 内部表示 | 说明 |
|------|--------|----------|------|
| `numeric` | `42`, `3.14`, `1.5e-10` | `int` / `float` | 整数和浮点数。R 中 integer 可加 `L` 后缀（如 `42L`），解析时 `L` 被去除 |
| `character` | `"hello"`, `'world'` | `string` (data section) | 字符串字面量，支持双引号、单引号、反引号三种定界符 |
| `logical` | `TRUE`, `FALSE` | `int` (1 / 0) | 布尔值映射为整数 |
| `NULL` | `NULL` | `int` (0) | 空值，R0 置零 |
| `NA` | `NA` | `int` (`int.MinValue`) | 缺失值，使用哨兵值表示 |
| `Inf` | `Inf` | `float` (`float.PositiveInfinity`) | 无穷大 |

注意：当前实现中 numeric 的 integer 和 float 在运行时不做严格类型区分。科学计数法（如 `1.5e-10`、`2E+3`）被完整支持。

##### 赋值运算符

R 支持三种赋值形式，优先级从高到低：

```r
# 1. 左赋值（推荐风格）
x <- 42
y <- c(1, 2, 3)

# 2. 等号赋值（函数参数风格）
x = 42

# 3. 超级赋值（父环境赋值）
x <<- 42
```

- `<-` 和 `=` 在当前作用域分配变量
- `<<-` 标记为超级赋值，用于向父作用域写入（当前编译器实现中与 `<-` 行为等价，作用域层级尚未完全实现）
- 赋值表达式返回右值，支持链式赋值：`a <- b <- 10`

##### 算术运算符

| 运算符 | 语法 | 说明 |
|--------|------|------|
| 加法 | `a + b` | 数值相加 |
| 减法 | `a - b` | 数值相减 |
| 乘法 | `a * b` | 数值相乘 |
| 除法 | `a / b` | 浮点除法 |
| 幂运算 | `a ^ b` | 指数运算 |
| 取模 | `a %% b` | 整数取余（注意必须为两个 `%` 符号） |

##### 比较运算符

| 运算符 | 语法 | 说明 |
|--------|------|------|
| 等于 | `a == b` | 相等比较 |
| 不等于 | `a != b` | 不等比较 |
| 小于 | `a < b` | 小于比较 |
| 大于 | `a > b` | 大于比较 |
| 小于等于 | `a <= b` | 小于或等于 |
| 大于等于 | `a >= b` | 大于或等于 |

比较结果返回整数 `1` (TRUE) 或 `0` (FALSE)。

##### 逻辑运算符

| 运算符 | 语法 | 说明 |
|--------|------|------|
| 逻辑与 | `a & b` | 短路求值 (映射为 `&&`) |
| 逻辑或 | `a \| b` | 短路求值 (映射为 `\|\|`) |
| 逻辑非 | `!a` | 一元取反 |

注意：当前实现不区分向量化的 `&`/`|` 和短路求值的 `&&`/`||`，所有逻辑运算均执行短路求值。R0 = 0 视为 FALSE，非零视为 TRUE。

##### 函数

```r
# 函数定义
add <- function(a, b) {
    return(a + b)
}

# 无参函数
greet <- function() {
    return("Hello")
}

# 隐式返回：函数体最后一个表达式的值即为返回值
square <- function(x) {
    x * x
}
```

- 使用 `function(params) { body }` 语法定义匿名函数，通过 `<-` 赋值给变量名
- 参数列表可以为空
- `return(expr)` 提前返回，`return expr`（无括号）也受支持
- 函数体最后一个表达式的值隐式作为返回值
- 函数调用：`name(arg1, arg2, ...)`，参数从右向左压栈，返回值在 R0 寄存器
- 函数内部有独立的变量作用域（参数压入当前栈帧，函数退出时恢复）

##### 控制流

###### if / else

```r
if (x > 0) {
    print("positive")
} else {
    print("non-positive")
}

# else if 链（嵌套解析）
if (x > 0) {
    print("positive")
} else if (x < 0) {
    print("negative")
} else {
    print("zero")
}
```

条件表达式求值后与 0 比较：`CMP R0, 0; JE`。非零为真。

###### while 循环

```r
i <- 1
while (i <= 10) {
    print(i)
    i <- i + 1
}
```

前测试循环：条件为假时跳过循环体。

###### for 循环

```r
for (i in 1:5) {
    print(i)
}

for (x in c(10, 20, 30)) {
    print(x)
}
```

- `for (variable in sequence) { body }` 语法
- 迭代变量在每次循环中被赋予序列的当前元素值
- 支持 `c()` 向量和范围表达式
- 序列长度在编译时确定（仅支持常量长度序列）

###### repeat 循环

```r
repeat {
    # 必须包含 break 条件，否则为无限循环
    if (condition) {
        break
    }
}
```

无限循环，必须使用 `break` 显式退出。

###### break 和 next

```r
# break: 退出最内层循环
for (i in 1:10) {
    if (i > 5) {
        break
    }
}

# next: 跳过当前迭代，进入下一次循环
for (i in 1:10) {
    if (i %% 2 == 0) {
        next
    }
    print(i)  # 只打印奇数
}
```

- `break` 跳转到循环结束标签
- `next` 跳转到循环条件检查标签（等价于 C 语言 `continue`）
- 在循环外使用会导致编译错误

##### 向量 (Vectors)

```r
# c() 构造函数
x <- c(1, 2, 3, 4, 5)
y <- c(TRUE, FALSE, TRUE)
z <- c()  # 空向量，返回 NULL

# 范围运算符
1:10    # 整数序列，解析为特殊调用
```

- 向量通过 `c()` 函数构造，在解析器中作为 `SeqNode` AST 节点特别处理
- 向量在堆上分配（`SYSCALL 2` = malloc），每个元素占 4 字节
- 元素按顺序存储在连续内存中
- 空向量 `c()` 返回 0 (NULL)
- 范围运算符 `start:end` 被解析为对 `:` 函数的调用
- **不支持**：命名向量、类型强制转换、向量回收（recycling）

##### 索引

```r
x <- c(10, 20, 30, 40)
a <- x[1]   # 10 (R 索引从 1 开始)
b <- x[3]   # 30
```

- 使用 `[index]` 语法，1-based 索引
- 内部实现：索引减 1，乘以 4（字偏移），从基址加载
- 索引表达式可以是任意表达式：`x[i + 1]`
- **不支持**：负索引（排除）、逻辑索引、多维索引、`[[` 提取运算符、切片 `x[2:4]`

##### 注释

```r
# 这是单行注释
x <- 1  # 行尾注释
```

仅支持 `#` 开头的单行注释。不支持多行注释。

##### 科学计数法

```r
x <- 1.5e-10   # 1.5 × 10^-10
y <- 2.0E+5    # 200000
z <- 3e8        # 300000000
```

词法分析器完整解析科学计数法：尾数、小数点、`e`/`E`、可选符号、指数。

##### 标识符规则

- 以字母、下划线或点号开头（点号后必须跟字母或下划线）
- 后续字符：字母、数字、下划线、点号
- 区分大小写：`x` 和 `X` 是不同的变量
- 关键字不可作为标识符使用
- 示例合法标识符：`x`, `_private`, `.hidden`, `my.var`, `data_1`

##### source() 导入

```r
source("lib/utils.r")
```

`source()` 调用以正则表达式从源码中提取（预处理阶段前解析），将指定的 `.r` 文件内容链接到当前程序。这是一个编译时机制，非运行时函数调用。

##### 寄存器约定

遵循 VML 标准调用约定：

| 寄存器 | 用途 |
|--------|------|
| R0 | 累加器 / 函数返回值 |
| R12 | 帧指针 (BP) |
| R13 | 栈指针 (SP) |
| R15 | 返回地址 (RA) |

##### 内存模型

- 局部变量：在栈帧内分配，通过 `R12-offset` 寻址
- 全局变量：在 data section 中分配，通过标签 `var_name` 寻址
- 未知变量首次赋值时自动在栈上分配空间（4 字节对齐）
- 向量元素：堆分配（`SYSCALL 2` / malloc），返回基址指针

##### 函数调用约定

- 参数从右向左压栈
- `CALL func_<name>` 跳转到函数体标签
- 被调函数：
  - 序言：`PUSH R15; PUSH R12; MOVE R12, R13`
  - 体：执行语句。参数在栈帧内通过 `R12-<offset>` 访问
  - 尾声：`POP R12; RET`
- 返回值通过 R0 传递

##### 字符串处理

- 字符串字面量存储在 data section 中，带唯一标签 `str_<guid>`
- 使用 `MOVE R0, label` 将字符串地址加载到 R0
- 重复字符串共享同一标签（通过 `_stringCache` 字典去重）

##### 标准输出

当前编译器无内置 `print()` 实现。输出需通过 VML SYSCALL 或 BIOS 调用实现，或链接 C 共享库中的 `printf` 函数。

##### R 转换为 VML 的典型映射

| R 构造 | VML 指令序列 |
|--------|-------------|
| `x <- 10` | `MOVE R0, 10; MOVE [R12-x], R0` |
| `a + b` | `MOVE R0, [R12-a]; MOVE R0, [R12-b]; ADD R0, R0, R0` |
| `if (x) { ... }` | `MOVE R0, [R12-x]; CMP R0, 0; JE else_label; ...; LABEL else_label` |
| `while (x) { ... }` | `LABEL while_start; MOVE R0, [R12-x]; CMP R0, 0; JE wend; ...; JMP while_start; LABEL wend` |
| `for (i in c(1,2,3)) { ... }` | 索引初始化 + 条件检查循环 + 每次迭代加载序列元素值 |
| `return(x)` | `MOVE R0, [R12-x]; POP R12; RET` |
| `f(x, y)` | `MOVE R0, [R12-y]; PUSH R0; MOVE R0, [R12-x]; PUSH R0; CALL func_f` |
| `v[i]` | 计算基址 + (i-1)*4，间接加载 |
| `c(1, 2, 3)` | `SYSCALL 2` (malloc 12) + 依次存储元素 + 恢复基址到 R0 |

- S3/S4 对象系统
- 图形设备

**保留**:
- 基本统计运算
- 向量操作 (c/seq/rep)
- print 映射到 UART

##### OS 模式（`--mode os`）
OS 模式支持全部语言特性。

##### RAM 级别
- `--ram k`：KB级别
- `--ram m`：MB级别（默认）
- `--ram g`：GB级别
