# 插件系统（编译期）

WayCoder 的插件是**编译进单文件 exe 的 C# 源码扩展**——无反射、NativeAOT 安全、性能与内置工具一致。它与已有的三种扩展机制互补：

| 机制 | 载体 | 适用场景 |
|------|------|----------|
| **插件**（本文） | C# 源码，编译进 exe | 需要原生性能、复杂逻辑、可复用工具/命令 |
| **SKILL.md 技能** | Markdown | 给模型一段工作流/知识，按需加载 |
| **Hooks** | 外部脚本 | 工具调用前后拦截、生命周期事件 |
| **MCP** | 外部服务器进程 | 接入第三方工具生态 |

## 三步写一个插件

### 1. 新建插件文件

在 `WayCoder/Plugins/` 目录新建 `.cs` 文件（SDK 自动编译该目录下所有 `.cs`，无需改 `.csproj`）。

### 2. 实现 `Plugin` 基类

插件可以贡献两类东西：**工具**（`ITool`，供大模型 function calling 调用）和**斜杠命令**（`ISlashCommand`，供用户在 REPL 输入 `/xxx`）。

```csharp
using WayCoder;
using WayCoder.Tools;

// 一个自定义工具：让大模型能「算 C# 里的圆周率」
public sealed class PiTool : ITool
{
    public string Name => "get_pi";
    public string Description => "返回圆周率 π（可指定小数位数）";
    public System.Text.Json.Nodes.JsonObject Parameters => new()
    {
        ["type"] = "object",
        ["properties"] = new System.Text.Json.Nodes.JsonObject
        {
            ["digits"] = new System.Text.Json.Nodes.JsonObject { ["type"] = "integer", ["description"] = "小数位数（默认 10）" },
        },
    };
    public Task<string> ExecuteAsync(Dictionary<string, object?> arguments)
    {
        var digits = arguments.TryGetValue("digits", out var d) && d != null ? Convert.ToInt32(d) : 10;
        return Task.FromResult($"π ≈ {Math.PI.ToString($"F{digits}")}");
    }
}

// 一个自定义斜杠命令：/hello
public sealed class HelloCommand : SlashCommand
{
    public override string Name => "/hello";
    public override string Description => "打印一句问候";
    public override Task ExecuteAsync(string args, WayCoder.UI.TuiScreens.ChatScreen screen)
    {
        screen.AddSystemMsg($"你好！参数 = {args}");
        return Task.CompletedTask;
    }
}

// 插件主体：把工具 + 命令打包
public sealed class MyPlugin : Plugin
{
    public override string Name => "my-plugin";
    public override string Version => "1.0.0";
    public override IEnumerable<ITool> GetTools() => [new PiTool()];
    public override IEnumerable<ISlashCommand> GetCommands() => [new HelloCommand()];
}
```

### 3. 自动注册（ModuleInitializer）

在同一个文件里加一段初始化代码，让插件随程序启动自动注册——**无需改动任何启动代码**：

```csharp
internal static class MyPluginInit
{
    [System.Runtime.CompilerServices.ModuleInitializer]
    internal static void Init() => PluginRegistry.Register(new MyPlugin());
}
```

### 4. 重新编译

```bash
dotnet publish -c Release
```

插件随单文件 exe 一起分发，启动即生效。

## 关键 API

| 成员 | 说明 |
|------|------|
| `IPlugin` | 插件接口：`Name`/`Version` + `GetTools()`/`GetCommands()` |
| `Plugin` | 抽象基类：`GetTools`/`GetCommands` 默认空，子类只覆写需要的部分 |
| `PluginRegistry.Register(plugin)` | 注册插件（同名忽略大小写后注册覆盖先注册，幂等） |
| `PluginRegistry.Unregister(name)` | 按名移除插件 |
| `PluginRegistry.CollectTools()` / `CollectCommands()` | 收集所有插件的工具/命令 |

插件贡献的工具会自动进入 `ToolRegistry.AllTools`（大模型可直接调用），命令会自动进入 `SlashCommandRegistry`（REPL 输入 `/xxx` 即可触发）。

## 注意事项

- **AOT 无反射**：不要用 `GetType`/`GetMethod`/`Assembly.Load` 动态加载，插件必须编译进主程序。
- **唯一性**：插件名与工具名/命令名需唯一，避免与内置 44 个工具、40+ 斜杠命令冲突。
- **命名**：建议插件文件用 `XxxPlugin.cs`，工具名用 `snake_case`（与内置工具一致），命令名用 `/kebab-case`。
