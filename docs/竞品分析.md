# WayCoder 竞品对比分析

> 更新：2026-08-18（v0.79.3）
> 目的：客观定位 WayCoder（道码）相对主流 AI 编程工具的优势与短板，为迭代方向提供参考。

## 1. 竞品定位

| 工具 | 定位 | 技术栈 |
|------|------|--------|
| Claude Code | 官方 Agentic 编码 CLI | 闭源，终端 + IDE + Web |
| Codex CLI | OpenAI 官方 | 开源 C#，终端 + IDE |
| Gemini CLI | Google 官方 | 开源 TypeScript |
| Cursor | 商业 AI IDE | 闭源，VS Code 分支 |
| Crush | 开源 Rust TUI（本项目对标对象） | 开源 Rust |
| Aider | 开源配对编程 | 开源 Python |
| **WayCoder（道码）** | 中文易用编程智能体 | C#/.NET 10 AOT 单文件 |

## 2. 各维度对比

| 维度 | WayCoder | Claude Code / Codex | Cursor | Crush |
|------|----------|---------------------|--------|-------|
| 界面 | TUI + Web + **GUI** 三端 | CLI + Web（无 GUI） | IDE | TUI |
| 模型绑定 | 双模型分工 + 回退链 + 模型库 | 官方模型（可用第三方） | 多模型 | 多模型 |
| 多会话 | F1-F10 真并行槽位 | 单会话为主 | Tab/窗口 | 多会话 |
| 中文体验 | 原生中文 UI + 文档 | 英文为主 | 中英 | 英文 |
| 部署形态 | AOT 单文件 exe | Node/Python 运行时 | 重型 IDE | Rust 二进制 |
| 安全 | BashGuard + 权限 + 路径防护 | 权限门 + 沙箱 | 权限 | 权限 |
| 扩展 | 插件/MCP/Hooks/Skills | MCP/Hooks/子代理 | 插件 | MCP |
| 多模态 | 视觉/音频（Whisper 转录） | 视觉（部分） | 视觉 | 有限 |
| 离线本地模型 | LM Studio/Ollama 一键 | 有限 | 有限 | 支持 |

## 3. 优点（WayCoder 强项）

1. **三端覆盖罕见**：同时有 TUI、Web、GUI 三种界面，且 GUI 版已对齐 Web。这个组合在竞品里独一份（Claude Code 无 GUI，Crush 只有 TUI）。

2. **模型生态自由度极高**：
   - 双模型架构（大模型干活 + 小模型压缩省钱）
   - 五级回退链（deepseek→gemini→qwen→glm→gpt）
   - 本地模型（LM Studio/Ollama）可用性实测修复
   - 模型按供应商分类存储 + OpenCode 在线导入

3. **AOT 单文件 + 手搓一切**：零反射手写 PNG/JPEG/PDF/Office/字体解析、绘图引擎——极端自包含，无供应链依赖风险，对安全审计有独特价值。

4. **中文原生**：界面、文档、提示词全中文，国内模型（DeepSeek/Qwen/GLM/Kimi）接入顺滑，这在英文主导的竞品中是明确差异点。

5. **工程密度惊人**：10 槽位真并行、批量任务引擎、跨会话记忆检索、Hook 系统、MCP 三传输、编辑器、Diff 预览——小团队/个人维护了堪比商业工具的功能集。

6. **自测意识强**：3500+ 自测覆盖边界（越界钳制、Rune 截断、解析器护栏），比多数开源竞品严谨。

## 4. 缺点（弱项 / 风险）

1. **生态与社区缺失**（最大短板）：Claude Code/Cursor 有海量插件、教程、企业集成；WayCoder 几乎无第三方生态，文档较少。

2. **闭源单点维护**：核心维护者少，Bus Factor = 1。竞品有公司团队持续迭代。

3. **性能/资源**：AOT 单文件虽快，但 TUI + Web + GUI 三套渲染各维护一份，15万行+ 代码维护成本高。

4. **Agent 能力与官方模型深度有差距**：Claude Code 与 Claude 模型深度融合（系统提示词/工具调优官方反复打磨）；WayCoder 对各家模型是"通用适配"，复杂任务（大型重构、长链 agentic 推理）可能不如官方工具稳。

5. **安全审计历史**：扫描发现过 BashGuard 白名单绕过、解析器崩溃、SSRF、路径穿越等 P0（已修复），安全模型尚需持续加固。

6. **缺 IDE 集成**（硬伤）：Claude Code/Codex 都有 VS Code/JetBrains 扩展，WayCoder 目前只有独立终端/Web/GUI，无法在编辑器内联工作。`--json` 输出模式已为 IDE 桥接铺路但未落地。

7. **依赖国内服务稳定性**：回退链依赖各家 API，任一家断服/限流影响体验；Gitee 单一代码托管是单点。

## 5. 一句话总结

**WayCoder 的独特价值 = 中文原生 + 三端覆盖 + 模型全兼容 + 极端自包含**，是一个工程能力极强的独立开发者作品，在自由度、自包含、中文场景上超过主流竞品；**主要短板是生态、团队规模和 IDE 集成**，以及与官方模型深度调优的差距。

## 6. 最值得补的方向

1. **VS Code / JetBrains 扩展**（`--json` 输出模式已经为 IDE 桥接铺路）
2. **预设的场景化技能包/模板**（对标 Claude Code 的 CLAUDE.md 生态）
3. **一份像样的中文文档站 + 示例**（目前 docs/ 较薄）
