## 一、各竞品最独到处（一句话）

| 竞品 | 语言/形态 | 最独到处 |
|---|---|---|

| **qwen-code** | TS | 推测执行(预执行+COW overlay 一键提交)；Agent 团队邮箱队列；多模型 Arena；微压缩 |
| **kilo** | TS(opencode fork) | OS seatbelt 沙箱+网络三态；多供应商向量语义检索；自动记忆捕获+预算召回 |
| **roo-code** | VS Code 扩展 | 每任务影子 git 检查点；tree-sitter 折叠签名骨架；无损截断可回放；请求数+成本双预算审批 |

## 二、高价值设计点（含源码佐证）

### Claude Code
- **Coordinator 多 worker 编排** `src/coordinator/coordinatorMode.ts`：`isCoordinatorMode`(L36)、`getCoordinatorUserContext`(L80) 给 worker 注入工具列表+scratchpad 共享目录、`getCoordinatorSystemPrompt`(L111) 专门系统提示(fan-out/自含 spec/continue vs spawn 决策矩阵 L282-293)。**跨 worker 共享 scratchpad 目录**(L104-106, 无权限提示读写) 是并行 agent 的知识交换层。
- **子 agent 生命周期作为一等工具集** `src/tools/{TaskCreate,TaskGet,TaskList,TaskOutput,TaskStop,TaskUpdate,SendMessage,TeamCreate,TeamDelete}Tool/`：把创建/列出/停止/续聊子任务暴露为模型可直接调用的工具。
- **frontmatter 技能系统** `src/skills/loadSkillsDir.ts` + `bundledSkills.ts`：技能是 markdown+frontmatter，含 `allowedTools/model/agent/hooks/context:inline|fork` 字段；可被 `mcpSkillBuilders` 转 MCP 工具，自带权限边界。
- **LSP 级代码智能** `src/tools/LSPTool/` + `services/lsp/manager.ts`：符号/诊断上下文喂模型；`FileEditTool.ts` 编辑后拉 LSP 诊断自校验。
- **稳健 FileEdit** `FileEditTool.ts`：1 GiB 文件守护(L84)、`findSimilarFile`/`suggestPathUnderCwd` 路径纠错(L22-27)、宽松匹配+引号风格保留(L73-77)、`fileHistoryTrackEdit`(L30)、git diff 校验(L39-42)。

### Gemini CLI
- **事件驱动 Scheduler** `packages/core/src/scheduler/scheduler.ts`：工具执行做成状态机(validating→scheduled→executing→terminal)+可中断队列；`schedule` 并行合批(L195/L472-483)；编辑类工具强制串行(L574)；`sandbox_expansion_required` 动态加权限重执行(L836-938)。
- **shell 解析式策略引擎** `packages/core/src/policy/policy-engine.ts`：递归拆子命令/bash -c/`&&`/`;`(L489-553)；重定向恒降级(L329-346)；非可信目录 git 命令强制 ASK_USER(L351-404)；subagent 名作为虚拟工具别名注入规则(L624-632)。
- **A2A 多 Agent 协议** `packages/core/src/agents/remote-subagent-protocol.ts`：本地/远程走同一 `AgentProtocol` 接口，`contextId/taskId` 跨调用持久化；专门 codebase-investigator 生成结构化调查报告。
- **OS 原生沙箱** `packages/core/src/sandbox/{linux,linux/macos,windows}/` + `services/sandboxedFileSystemService.ts`：可选 bubblewrap + 受限文件系统 + 用户批准后动态扩权限。
- **git worktree 隔离** `services/worktreeService.ts`：`createWorktree` 建 `.gemini/worktrees/<name>` 独立分支，完成自动回收(L151/L186)。

### Continue
- **流式 diff 增量编辑** `core/diff/streamDiff.ts`：`async function* streamDiff` 边生成边应用，含缩进容错匹配(L20-34)。
- **NextEdit 预测** `core/nextEdit/`：以用户上一次 diff 为触发，预测模型下一次整块编辑(±5 行可编辑区)，Tab 接受。
- **多路落盘索引** `core/indexing/CodebaseIndexer.ts`：FTS + 向量(LanceDb) + 代码片段 + chunk 多路索引，后台批处理可暂停(filesPerBatch=200)。
- **shell 安全分类器** `packages/terminal-security/evaluateTerminalCommandSecurity.ts`：约 20 类高风险 + 命令替换提取(反引号/`$()`/进程替换 L1100+)+ 混淆检测(base64/hex/printf L1192)；解析失败 fail-closed。
- **Hub&Spoke 多前端** `core/core.ts` + `core/continueServer/` + `extensions/{cli,vscode,intellij}`：单核心服务三 UI；autocomplete 预过滤→分类→生成→后处理流水线。

### aider
- **PageRank 个性化 repo 地图** `repomap.py` L365-574：tree-sitter 建定义/引用图(`nx.MultiDiGraph`)+`nx.pagerank` 排序；**正被编辑/提及的文件动态加权**(personalization L374-445, mul*=10)。
- **双模型拆「想/改」** `coders/{editblock_coder,architect_coder}.py`：ArchitectCoder 让规划模型生成方案、editor_model 用 editor_edit_format 落盘。
- **git 原生工作流** `coders/base_coder.py` L2175-2292/L2375-2415：每次编辑自动 commit + `/undo` 按提交回退 + 脏提交前置提交。
- **流式部分 diff 展示** `diffs.py` L43-102：只对已生成前半段做 unified diff + 进度条，低延迟可视化「正在改哪里」。

### codex
- **跨平台进程级沙箱** `sandboxing/src/manager.rs` + `core/exec_policy.rs`：Seatbelt/Landlock/RestrictedToken；`BANNED_PREFIX_SUGGESTIONS` 危险命令前缀黑名单(100+);`safety.rs` `assess_patch_safety` → AutoApprove/AskUser/Reject。
- **结构化 apply_patch** `codex-rs/apply-patch/src/parser.rs` + `file_update.rs`：`*** Begin Patch/Update/Move to/End of File` 多 hunk；文件移动 + `similar::TextDiff` 近似匹配(容忍行漂移)。
- **上下文压缩一等流水线** `core/compact.rs`：`COMPACT_USER_MESSAGE_MAX_TOKENS=20000`、`InitialContextInjection`、`CompactedHistoryMetadata`、pre/post-compact hooks、remote compaction、图像预算。
- **持久化线程衍生 DAG** `agent-graph-store/src/store.rs`：`upsert_thread_spawn_edge` / `list_thread_spawn_descendants`，可恢复子 agent 拓扑。
- **headless JSON-RPC app-server** `app-server/src/lib.rs`：CLI/IDE 走同一 JSON-RPC 协议，可嵌入式多客户端。

### crush
- **LSP 语义工具集** `internal/agent/tools/lsp_{definition,rename,call_hierarchy,symbols,replace_symbol}.go`：跳定义/重命名重构/调用层级/符号列表/替换符号，经 `lsp.Manager` 驱动。
- **agent 子代理委托** `internal/agent/{agent_tool,coordinator}.go`：`AgentToolName="agent"`，`runSubAgent` 起独立 session 并行 agent。
- **工具循环自检测** `internal/agent/loop_detection.go`：把 `ToolName+Input+结果` 做 SHA-256 签名，窗口 10 重复 >5 判定死循环。
- **会话级持久授权 + hook 预审批短路** `internal/permission/permission.go`：`PermissionKey=SessionID+ToolName+Action+Path` + `GrantPersistent`；hook 返回审批直接短路。
- **跨客户端共享工作区** `README.md` L443-466：多客户端共享会话列表/消息历史/权限队列/LSP/MCP 状态。

### goose
- **操作符状态机主循环** `crates/goose/src/agents/state_machine/mod.rs`：主循环拆成命名 operator(`ops_tool_approval/ops_recipe/ops_skills/ops_compaction/ops_steer/ops_retry`)，可重入/可测。
- **LLM 只读判定权限** `permission/permission_judge.rs`：用轻量 LLM 判定待定工具是否只读，自动放行只读(R41-89)，防提示注入(L66-70)。
- **审批元数据回写** `agents/state_machine/ops_tool_approval.rs`：`mark_executable` 用 `PatchToolRequestMeta` 把审批写回会话 + 安全事件埋点(L135-145)。
- **MOIM turn-context** `agents/moim.rs`：当前时间/工作目录/压缩状态/回合预算组合成 `<turn-context>` 稳定块；仅 agent 可见(L124-139)；小上下文模型跳过。
- **结构化子代理** `subagent_handler.rs`：独立 provider/model，`final_output_tool` 用响应 schema 返回类型化结果。

### opencode
- **LSP 一等服务** `packages/opencode/src/lsp/lsp.ts` L110-140：hover/definition/references/implementation/调用层级/documentSymbol/workspaceSymbol/diagnostics。
- **命令 arity 解析** `permission/arity.ts`：最长前缀匹配把 shell 命令解析成有含义命令段(`git checkout main`→arity 2，flag 不计)，权限显示命令本体。
- **整文件 patch 移动+EOF** `patch/index.ts`：`*** Add/Update/Delete/Move to/End of File` 标记符，EOF 哨兵让长文件追加不失败。
- **隔离 --git-dir 快照** `snapshot/index.ts`：影子 git 目录逐 worktree 做时间机，回滚不污染真实历史。

### qwen-code
- **推测执行** `core/src/followup/speculation.ts`：先展示建议 → 后台 fork LlmChat+COW overlay 跑只读工具 → Tab 一键提交(写回真实 FS)、输入中止(R57-58)。
- **Agent 团队邮箱队列** `core/src/agents/team/`：`TeamManager`(中心编排/优先级路由/空闲检测/任务认领) + `identity.ts`(AsyncLocalStorage 带队友身份) + `mailbox.ts` + `leaderPermissionBridge`。
- **Agent Arena 多模型并跑** `agents/arena/ArenaManager.ts`：git worktree 隔离 + PTY 子进程并跑，统一 diff 摘要对比。
- **微压缩** `services/microcompaction/microcompact.ts`：`COMPACTABLE_TOOLS` 白名单(工具粒度清旧结果)+占位符。
- **Goals 运行时** `goals/goal-runtime.ts`：带证据目录/检查点/验证器的目标状态机，可检测卡死。

### kilo
- **OS seatbelt 沙箱+网络三态** `packages/kilo-sandbox/src/seatbelt.ts` + `seatbelt-network.ts`：sandbox-exec 策略 allow/proxy/deny 网络。
- **多供应商向量索引** `packages/kilo-indexing/src/indexing/embedders/`：bedrock/gemini/mistral/ollama/openai/... 可插拔 + LanceDB/Qdrant 向量库 + 语义检索。
- **自动记忆** `packages/kilo-memory/src/{capture,recall}/`：自动捕获 diff/结果/计划→脱敏→摘要；`recall.ts` 按 topic/预算召回。
- **一芯多端**：kilo-jetbrains / kilo-vscode / CLI / cloud / gateway / telemetry。

### roo-code
- **每任务影子 git 检查点** `src/services/checkpoints/RepoPerTaskCheckpointService.ts`：shadowDir/tasks/<taskId> 独立影子仓库，根目录 `core/checkpoints/index.ts`。
- **tree-sitter 折叠签名骨架** `core/condense/foldedFileContext.ts`：抽取函数/类签名包成 `<system-reminder>` 块压缩上下文。
- **无损滑动窗口截断** `core/context-management/index.ts`：截断用 `truncationParent` 打标隐藏+marker、可回退；先 `summarizeConversation` 浓缩再截断。
- **请求数+成本双预算自动审批** `core/auto-approval/AutoApprovalHandler.ts`：`checkRequestLimit/checkCostLimit`，超限转人工。
- **模糊多段替换 diff + 外部 Codex 委托** `core/diff/strategies/multi-search-replace.ts`(Levenshtein 中点向外模糊匹配) + `integrations/openai-codex/oauth.ts`(OAuth 登录 Codex/ChatGPT)。

## 三、与 WayCoder 现状对照

### 已具备（无需学）
多 Agent 槽位(F1-F10 并行)、权限行内确认/YOLO、MCP 三传输、上下文压缩三层+小模型摘要、结构化记忆+TF-IDF 检索、编译期插件、`--batch` 多仓库 worktree 隔离、TUI/Web/GUI/MAUI 多前端、Hooks、`edit_file` 唯一子串、SHA256 循环检测、自绘图像/字体、多端会话隔离。

### 可借鉴（中小改动 · 高收益）

| # | 点 | 来源 | 落地到 WayCoder |
|---|---|---|---|
| 1 | **Shell 安全矩阵 + 命令本体 arity** | opencode/continue/codex | 升级 `BashGuard`：递归拆子命令(`&&`/`;`/bash -c)、命令本体显示、混淆检测、重定向恒降级 |
| 2 | **折叠签名骨架 + 微压缩** | roo/qwen | 改 `ContextManager`：tree-sitter 折叠已读文件为签名；按工具粒度清旧工具结果 |
| 3 | **编辑后 LSP 诊断自校验** | claude/crush | `EditFileTool` 编辑后拉 `LspTool` 诊断反馈 |
| 4 | **repo 上下文 PageRank 个性化** | aider | 上下文注入时对「正编辑/提及的文件」动态加权 |
| 5 | **会话级持久授权 + 双预算自动审批** | crush/roo | 增强权限记忆 + 请求数/成本滚动预算兜底 |
| 6 | **工具循环自检测强化** | crush | 已有 SHA256 循环检测，可采「工具调用+结果签名」更精准 |

### 待引入（差异化 · 工程较大，WayCoder 未覆盖）

|---|---|---|---|

## 四、性价比 Top 3（建议优先）

1. **Shell 安全矩阵 + 命令本体 arity**（🔶 小/中，改 `BashGuard`）→ 权限 UX + 安全性双升
2. **折叠签名骨架 + 微压缩**（🔶 小/中，改 `ContextManager`）→ 大幅降 token、保上下文质量
3. **编辑后 LSP 诊断自校验**（🔶 小，改 `EditFileTool`+`LspTool`）→ 编辑质量立竿见影
