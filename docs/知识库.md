# 自主学习编程知识库（/kb）

WayCoder 的自主学习知识库：把**工作痕迹自动提炼成经验**，全局保存（`~/.waycoder/kb/`），跨项目积累个人编程经验，用于**提高编程技能与经验水平**。

## 核心理念

最有价值的知识不是教科书（网上随时可查），而是**你自己踩过的坑和做过的决策**。WayCoder 每天生产这种素材（git 提交、错误日志、修复记录），`/kb mine` 把它们自动转成结构化经验条目。

## 知识分类

每条经验归类为五类之一：

| 类别 | 含义 | 示例 |
|---|---|---|
| `mistake` | 容易犯的错误（反模式/踩坑） | git push 被拒不裸 force，先 fetch+rebase |
| `bugfix` | 复杂 bug 修复过程（现象→根因→修复→教训） | CI 无终端 `Console.WindowWidth` 返回 0 导致崩溃 |
| `habit` | 个人使用习惯/工作偏好 | 子智能体靠「不给工具」约束，不靠规则 |
| `gap` | 欠缺的知识（一条一知识点） | AOT 编译禁止运行时反射 |
| `code` | 可复用的代码片段 | `VisualToCol` 视觉列→字符列换算 |

条目支持 **文字 / 代码片段 / Markdown / 链接**（存储为纯 frontmatter md 文件；图片/音频暂不支持）。

## 命令

### `/kb`（`/mind` 为别名）

| 子命令 | 作用 |
|---|---|
| `/kb mine [N]` | 从最近 N 个 git 提交提炼经验（默认 20）。经**小模型**归纳为 JSON（现象/根因/修复/教训/标签/欠缺知识）；LLM 不可用时降级为基础条目 |
| `/kb save [类别] <内容>` | 手动记住一条（自动带日期上下文，类别自动识别或显式指定） |
| `/kb update <关键词> <新内容>` | 更新最匹配条目 |
| `/kb forget <内容>` | 忘记（删除）最匹配条目 |
| `/kb search <内容>` | TF-IDF 查找相关条目 |
| `/kb review` | **间隔重复自测**：展示「现象+根因」提问，揭示「修复+教训」；掌握→间隔 1→3→7→14→30 天递增，未掌握→重置 1 天+相关欠缺知识权重提升 |
| `/kb weak` | 欠缺知识清单 + 薄弱标签统计 + ErrorLog 错误信号 |
| `/kb list` | 列出全部条目 |

### CLI 形式

```bash
waycoder --kb mine 20     # 提炼最近 20 个提交
waycoder --kb weak        # 薄弱点统计
waycoder --kb review      # 间隔重复自测（非交互=学习模式）
waycoder --kb save "今天学会了 XX"   # 手动记录
```

## 运行时检索

聊天中 Agent 遇到**不熟悉的术语或疑似 bug**时，会调用 `kb` 工具在全局知识库检索相关经验（TF-IDF 复用 `SemanticMemory`）。启动时 `SystemPrompt` 也会把与项目特征匹配的经验自动注入系统提示词。

## 存储与分享

- 条目存 `~/.waycoder/kb/*.md`（标准 frontmatter，复用 `StructuredMemory.ParseFrontmatter` 解析）
- 复习调度状态存 `~/.waycoder/kb/kb.json`
- 纯文本文件便于将来分享（导出/ git-sync，复用 `SharedMemoryManager` 模式）

## 自测

`[知识库经验]` 节覆盖：存储 round-trip、四类过滤、LLM JSON 解析（BuildEntry）、gaps 提取、复习调度（PickNextDue/MarkReview）、weak 统计、ErrorLog 信号、`/mind` 别名匹配、`kb` 工具检索。完整自测 `dotnet run -- --test`。
