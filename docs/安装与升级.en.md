# Installation and Upgrade

[简体中文](安装与升级.md) | **English**

Dolaima supports a **built-in auto-upgrade** (self-replacement with a single command), and can also be installed through the winget / brew / apt distribution channels.

## 1. Direct Download (Cross-platform)

Download the archive for your platform from [GitHub Releases](https://github.com/alecksty/waycoder/releases). Unpacking it gives you a single-file `waycoder` / `waycoder.exe`; copy it into any directory on your PATH and you are done — no .NET runtime required.

> **GitHub is the only distribution channel**: the source repository lives on Gitee (private), while **binary releases and downloads always go through GitHub** —
> Releases, the winget manifest, the brew formula and the apt repository all point to GitHub.

| Platform | Artifact |
|---|---|
| Windows x64/arm64 | `waycoder-<version>-win-x64.zip` / `-win-arm64.zip` |
| macOS x64/arm64 | `waycoder-<version>-osx-x64.tar.gz` / `-osx-arm64.tar.gz` |
| Linux x64/arm64 | `waycoder-<version>-linux-x64.tar.gz` / `-linux-arm64.tar.gz` |

## 2. Installing via Package Managers

### winget (Windows)

Once submitted to winget-pkgs:

```powershell
winget install Aleckstygit.Dolaima
```

Install locally without submitting (see `packaging/winget/README.md`).

### Homebrew (macOS)

```bash
brew tap alecksty/waycoder
brew install waycoder
```

> The gitee mirror tap that used to be in the docs has been removed — that repository is private (anonymous access returns 403), so nobody could install from it.

### apt (Debian/Ubuntu)

**The apt repository is live on GitHub Pages** (`https://alecksty.github.io/waycoder/`, signing GPG key `E7481814D92CD89A`):

```bash
# 1. Import the signing key (it must be a binary keyring; ASCII-armored keys give NO_PUBKEY)
sudo mkdir -p /etc/apt/keyrings
sudo curl -fsSL https://alecksty.github.io/waycoder/waycoder.gpg -o /etc/apt/keyrings/waycoder.gpg

# 2. Add the apt source
echo "deb [signed-by=/etc/apt/keyrings/waycoder.gpg] https://alecksty.github.io/waycoder stable main" \
  | sudo tee /etc/apt/sources.list.d/waycoder.list

# 3. Install / upgrade
sudo apt update && sudo apt install waycoder
```

> The repository contains amd64 + arm64 (currently v0.96.36). GitHub Pages runs on github.com infrastructure, so networks in mainland China need to be able to reach github.com.

See `packaging/apt/README.md` and `packaging/apt/RELEASE.md`.

## 3. Built-in Auto-upgrade

### Interactive (inside the REPL)

| Command | Effect |
|---|---|
| `/update` | Check for a new version and show the current/latest version plus the changelog |
| `/update now` | Download the archive matching the current platform and **self-replace** |

On startup it silently checks once in the background, and shows a notice at the top of the chat stream when a new version is found.

### One-shot (scripts / CI)

```bash
waycoder --update        # check and self-upgrade; exits idempotently if already latest
```

### Self-replacement Mechanism

- **Windows**: a running exe cannot be overwritten, so it drops a retry script with `waycoder.exe.new` + `waycoder.upgrade.bat`; after exit it replaces the binary automatically and restarts.
- **macOS / Linux**: an atomic `rename` overwrites the running binary (the old inode keeps serving the current process); quit and relaunch to get the new version.

### Version Source (configurable)

Auto-upgrade checks **Gitee Releases** first (fast in mainland China) and falls back to **GitHub Releases** on failure. The repositories can be overridden with environment variables:

| Environment variable | Default |
|---|---|
| `WAYCODER_GITHUB_REPO` | `alecksty/waycoder` |
| `WAYCODER_GITEE_REPO` | `aleckstygit/my-coder` |

## 4. Publishing a New Release

1. Commit your code, then tag it: `git tag v0.48.7 && git push origin v0.48.7`
2. Run `bash scripts/release.sh` **on your own machine**: it builds all 6 platforms with NativeAOT, computes the SHA256 sums, generates the winget / brew manifests, and prints the commands to create the Release and upload `dist/`. (There is **no CI** — `.github/workflows/` was removed on 2026-09-30, so release binaries come only from the local `dist/`, and the manifest sha256 is tied to it.)
3. A Gitee Release is optional, for archival only (the 1 GB attachment quota is nearly full).
4. Commit the updated winget / brew manifests as needed (see the READMEs under `packaging/`)
