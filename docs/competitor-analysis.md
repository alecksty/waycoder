# CoreCoder 竞品分析与差异化策略

> v0.14.0 | 2026-08-07

## 一、竞品概况

| 产品 | 技术栈 | 部署 | 定价 | 核心优势 |
|------|--------|------|------|---------|
| **Claude Code** | Node.js/TypeScript | npm 全局安装 | Claude API 按量 | 深度推理、大上下文 |
| **OpenCode** | Rust | cargo 安装 | 自带模型免费 | 开源、本地优先 |
| **Cursor** | Electron/TypeScript | 安装包 | $20/月订阅 | GUI 体验、LSP 深度集成 |
| **GitHub Copilot** | - | IDE 插件 | $10/月 | IDE 深度集成 |
| **Windsurf** | Electron | 安装包 | $15/月 | 多文件编辑、Flow 模式 |
| **Aider** | Python | pip 安装 | 自带模型免费 | 开源、Git 原生集成 |
| **CoreCoder** | **C# .NET AOT** | **单文件 exe** | **自带模型** | **零依赖、瞬时启动、中文原生** |

## 二、CoreCoder 差异化优势

### 2.1 部署优势 (竞品做不到)

```
竞品: npm install -g / cargo install / brew install / 下载安装包
我们:   scp corecoder server:/usr/local/bin/  ← 一个文件, 3秒搞定
```

| 指标 | CoreCoder | Claude Code | OpenCode | Cursor |
|------|-----------|-------------|----------|--------|
| 文件大小 | ~15MB AOT | ~200MB (node_modules) | ~30MB | ~500MB |
| 启动时间 | <0.1s | ~1s | ~0.5s | ~3s |
| 内存占用 | ~50MB | ~200MB | ~100MB | ~500MB |
| 运行依赖 | **零** | Node.js 18+ | 无 | 安装包 |
| 离线可用 | ✅ AOT | ❌ | ✅ | ❌ |

### 2.2 中文原生适配

- CJK 宽度计算 (wcwidth 级别)
- 全角/半角自动兼容
- 中文语法高亮支持
- 中文提示和错误信息
- 竞品: 英文优先，中文显示经常错位

### 2.3 文件锁机制

- 多 Agent 并发安全
- 30s 超时自动释放
- 侧栏可视化锁状态
- **竞品均无此功能**

### 2.4 双模型架构

- 大模型处理复杂任务，小模型处理压缩/摘要
- 自动分工，省钱 50%+
- 运行时无感切换

## 三、竞品值得学习的功能

### 3.1 高优先级 (应该做)

| 功能 | 竞品参考 | 价值 | 工作量 |
|------|---------|------|--------|
| **本地项目知识库** | Claude Code Memory | 跨会话项目理解 | 中 |
| **可视化 Diff/Merge** | OpenCode 终端 diff | 修改前预览+逐块接受 | 中 |
| **对话历史搜索** | Claude Code Ctrl+R | 找回历史对话 | 小 |
| **批量任务引擎** | OpenCode Worktree | 多仓库并行处理 | 大 |
| **MCP 工具市场** | Claude Code MCP | 扩展生态 | 中 |

### 3.2 中优先级

| 功能 | 说明 |
|------|------|
| 自定义系统提示词模板 | 不同项目/语言自动切换 prompt |
| 快捷键自定义 | 用户可配置快捷键 |
| 终端内图片查看 | ASCII art / sixel 渲染 |
| LSP 诊断面板 | 实时错误/警告显示 |
| 自动 Git 提交 | Agent 完成后自动生成 commit message |

### 3.3 低优先级

| 功能 | 说明 |
|------|------|
| GUI 模式 | 非终端版本 |
| 语音输入 | 需额外 SDK |
| 团队协作 | 多用户共享会话 |
| 插件市场 | C# 编译插件 |
