# 安装与升级

WayCoder 支持**内置自动升级**（一条命令自替换），也可通过 winget / brew / apt 分发渠道安装。

## 一、直接下载（跨平台）

从 [Gitee Releases](https://gitee.com/aleckstygit/my-coder/releases)（或 GitHub Releases）下载对应平台压缩包，解压即得单文件 `waycoder` / `waycoder.exe`，拷贝到任意 PATH 目录即可，无需 .NET 运行时。

| 平台 | 产物 |
|---|---|
| Windows x64/arm64 | `waycoder-<版本>-win-x64.zip` / `-win-arm64.zip` |
| macOS x64/arm64 | `waycoder-<版本>-osx-x64.tar.gz` / `-osx-arm64.tar.gz` |
| Linux x64/arm64 | `waycoder-<版本>-linux-x64.tar.gz` / `-linux-arm64.tar.gz` |

## 二、包管理器安装

### winget（Windows）

提交到 winget-pkgs 后：

```powershell
winget install Aleckstygit.WayCoder
```

本地免提交安装（见 `packaging/winget/README.md`）。

### Homebrew（macOS）

```bash
brew tap aleckstygit/waycoder
brew install waycoder
```

### apt（Debian/Ubuntu）

**apt 仓库已上线 GitHub Pages**（`https://alecksty.github.io/waycoder/`，签名 GPG `E7481814D92CD89A`）：

```bash
# 1. 导入签名密钥（必须是二进制 keyring，ASCII 装甲会报 NO_PUBKEY）
sudo mkdir -p /etc/apt/keyrings
sudo curl -fsSL https://alecksty.github.io/waycoder/waycoder.gpg -o /etc/apt/keyrings/waycoder.gpg

# 2. 添加 apt 源
echo "deb [signed-by=/etc/apt/keyrings/waycoder.gpg] https://alecksty.github.io/waycoder stable main" \
  | sudo tee /etc/apt/sources.list.d/waycoder.list

# 3. 安装 / 升级
sudo apt update && sudo apt install waycoder
```

> 仓库含 amd64 + arm64（当前 v0.96.36）。GitHub Pages 基于 github.com 基础设施，国内网络需能访问 github.com。

见 `packaging/apt/README.md` 与 `packaging/apt/RELEASE.md`。

## 三、内置自动升级

### 交互式（REPL 内）

| 命令 | 作用 |
|---|---|
| `/update` | 检查新版本，显示当前/最新版本 + 更新日志 |
| `/update now` | 下载匹配当前平台的压缩包并**自替换** |

启动时会后台静默检查一次，发现新版本在聊天流顶部提示。

### 一次性（脚本 / CI）

```bash
waycoder --update        # 检查并自升级，已最新则幂等退出
```

### 自替换机制

- **Windows**：运行中的 exe 无法覆盖，落 `waycoder.exe.new` + `waycoder.upgrade.bat` 重试脚本，退出后自动替换并重启。
- **macOS / Linux**：原子 `rename` 覆盖运行中二进制（旧 inode 继续服务当前进程），退出重开后即新版本。

### 版本来源（可配置）

自动升级优先查 **Gitee Releases**（国内快），失败回退 **GitHub Releases**。仓库可用环境变量覆盖：

| 环境变量 | 默认值 |
|---|---|
| `WAYCODER_GITHUB_REPO` | `alecksty/waycoder` |
| `WAYCODER_GITEE_REPO` | `aleckstygit/my-coder` |

## 四、发布新版本

1. 提交代码后打 tag：`git tag v0.48.7 && git push origin v0.48.7`
2. GitHub Actions（`.github/workflows/release.yml`）自动 NativeAOT 编译 4 个平台并创建 Release + 上传资产
3. 若用 Gitee Release，用 `scripts/package.sh` 手动打包后上传附件
4. winget / brew 清单按需更新版本号与 sha256（见 `packaging/` 下各 README）
