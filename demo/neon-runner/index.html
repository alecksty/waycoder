CREDITS

Neon Runner — a complete 3D web game built with vanilla JavaScript + Three.js.

  • 🎮 Engine: Three.js (CDN) — WebGL renderer, PBR materials, dynamic lighting
  • 🧠 AI: Procedural track generation, physics simulation, AABB collision
  • 🔊 Audio: Web Audio API — fully procedural SFX (no asset files)
  • 🎨 Visuals: Custom CSS neon glow, particle systems, fog & bloom
  • 📐 Code: Pure ES6 modules, no build step required
