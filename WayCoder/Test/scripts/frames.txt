#
# 用法：waycoder --keypad Test/scripts/frames.txt
# 看 FRAMES 输出：内容未变的帧应当**只碰动画行（动态栏）与光标行**，
# 字节数也很小（约 40B）；若某帧字节数骤增、涉及行里出现聊天区/标题栏，即为区域联动。
#
# 判读要点：
#   rows=[17,19]  bytes≈39   → 正常：只有动态栏 spinner 直写 + 输入区光标
#   rows 里出现 1/2..16/18-24 且 bytes 很大 → 有东西把整屏拖进了重绘

FRAMES:6                # 连续 6 帧：稳态应每帧都只碰 17/19 行
