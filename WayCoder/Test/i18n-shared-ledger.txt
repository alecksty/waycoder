# 判据由 SelfTest.Localization.Ledger.cs 的 SharedScope 执行，**两个方向都会红**：
#   文件有中文但不在本表 => 红（新写的中文 / 新文件）
#   文件在本表却已零命中 => 红（台账腐烂会让「还剩多少」永远算不准）
#
# 「已迁移」的判据：中文已包在 L.Pick(中文, English) 里 —— 中文支是「键」，不算未迁移。
# 所以翻完一个文件就把它从本表删掉。
#
# 范围：**编译进手机**的那部分共享层。排除 UI/TUI（终端界面）、UI/Web（浏览器前端）、
# Config（设置项标签，已核实 MAUI 一行都不消费）、Test。三者都是**桌面外壳**，属更后面的批次。
#
# 口径（与 MAUI 侧一致，写在这里免得下一个人猜）：
#   · 用户能看见的字 ⇒ 翻（工具输出 / 错误提示 / 斜杠命令回显 / 注入给模型的散文 / 拒绝原因）
#   · 写进日志的（ErrorLog/DiagLog/Logging）⇒ **不翻**（与桌面侧既有约定一致）
#   · 判据/协议/存储键 ⇒ 不翻（翻了判据恒假，不报错）
#   · 公理 A2：凡「拿文案当判据」的地方，改显示侧时判据侧要改成中英都认
