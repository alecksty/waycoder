# 🛩️ Sky Strike 苍穹突袭

一个纯前端实现的竖版飞机空战射击游戏。无外部依赖、无图片资源，
飞机/子弹/爆炸全部由 Canvas 程序化绘制，音效由 Web Audio API 实时合成。

## 🎮 玩法

- **移动**：`W A S D` 或 `方向键`；鼠标/触屏按住拖动飞机跟随指针
- **射击**：按住 `空格` 或鼠标左键连发
- **暂停**：`P` 或 `Esc`
- **开始 / 重开**：`Enter` 或点击按钮

## 🚀 游戏要素

| 要素 | 说明 |
|------|------|
| 敌机 | 侦察机(快/脆)、战斗机(摆荡)、轰炸机(血厚/投弹)、无人机(编队)、Boss(每 5 波) |
| 道具 | 🔺 火力升级(单发→双发→三发→五发)、🛡 护盾(抵挡一次伤害)、💣 清屏炸弹 |
| 生命 | 3 条命，被撞或被弹幕击中扣除 |
| 计分 | 敌机分值 + 连击加成，最高分存入 localStorage |
| 难度 | 波次递增：敌机速度/血量随时间强化 |

## 🧩 文件结构

```
index.html            页面骨架 + 脚本加载顺序
css/style.css         全屏样式、HUD、菜单动画
js/config.js          所有数值配置（集中可调）
js/utils.js           数学/随机/绘制工具
js/input.js           键盘/鼠标/触屏输入管理
js/audio.js           Web Audio 合成音效
js/background.js      视差星空 + 流星
js/particle.js        粒子系统（爆炸/尾焰）
js/bullet.js          子弹实体（玩家/敌机/激光）
js/enemy.js           5 种敌机 + Boss
js/player.js          玩家飞机 + 射击 + 道具状态
js/wave.js            波次调度器（事件队列）
js/ui.js              HUD + 菜单 + 血条绘制
js/game.js            主循环 + 状态机 + 碰撞
js/main.js            入口启动
```

## 🚀 运行方式

直接用浏览器打开 `index.html` 即可（双击即可，无需服务器）。

## 🎚 调参

所有可调数值集中在 `js/config.js`，改完刷新即生效。
